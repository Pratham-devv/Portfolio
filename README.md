# Portfolio

My personal portfolio website showcasing my projects, skills, and experience as a Full-Stack Developer and AI Engineer.

## 🌐 Live Demo

[**View Portfolio**](https://portfolio-hazel-nine-z00u7cbq3x.vercel.app/)

## ✨ Features

- Responsive design that works on all devices
- Project showcase with live links
- Skills and tech stack section
- Contact information and social links
- Smooth animations and transitions

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Deployment:** Vercel
- **Styling:** Custom CSS + Tailwind

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/pratham-devv/Portfolio.git

# Navigate to the client directory
cd client

# Install dependencies
npm install

# Start the development server
npm run dev
```
